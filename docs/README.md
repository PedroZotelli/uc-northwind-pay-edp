# Docs — signed reference manuals

These three files are the engagement's reference library. They are not
the use case, and they are not last-run answers. Open them when the
room needs the method, the boot framing, or the Converge spine.

| Manual | What it is |
|---|---|
| [`asd-agentic-loop.html`](asd-agentic-loop.html) | ASD — the Agentic Loop. Five layers, hop map, how Converge sits on that anatomy |
| [`boot-uc-northwind-pay-edp-oss.html`](boot-uc-northwind-pay-edp-oss.html) | Bootcamp reference. Case framing, Shapiro ladder, the week arc |
| [`cvg-aut-systems-spine-steps.html`](cvg-aut-systems-spine-steps.html) | Converge spine. Nine passes, two phases, one human barrier |

They do not replace [`plans/`](../plans/README.md). Plans steer the
repository. These manuals teach the methods the week uses on top of it.

## What this folder is not

- Not contracts, fixtures, or expected outputs.
- Not a second copy of the legacy or modern plans.
- Not a place for last-run ADRs, Converge working papers, or detector
  findings. Those are written during the week, if they are written at all.

## Sign-off

The three manuals above are the set. A type, a gate, or a later factory
does not start from a missing PDF in this folder.
