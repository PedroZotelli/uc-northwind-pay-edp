EDITORIAL RULES The sixteen rules · §12 CONVERGE · 0.2.0

Sixteen rules this book held itself to. Any page breaking one is a defect.

The editorial contract, condensed from §12 — claim discipline is part of the product.

rule 01
Name it factory coordinator, assurance layer, or referee — never the autonomous reasoning engine.
rule 02
Say "nine passes, two phases, one barrier"; Capture optional and Register opt-in whenever the full spine appears.
rule 03
Keep topology acceptance, task authorization, runtime binding, execution, acceptance, and observation visually separate.
rule 04
reviewed, materialized, green, settled, accepted are never synonyms.
rule 05
LOCAL_SETTLED when external writes are denied; SETTLED only for explicitly permitted publication.
rule 06
Task-Spec 3.8.x compatibility stays explicit — no standalone 3.9 behavior in Converge 0.2.0.
rule 07
Guided chat and 60-form CLI content stay W · CHECKOUT ONLY until committed and re-proven.
rule 08
Hosted/release statements are reported or immutable; local reruns do not prove remote publication.
rule 09
The layout failure lives in the main narrative, not a footnote.
rule 10
HMAC is tamper evidence under a shared key — not identity, not isolation.
rule 11
Tier-2 holdout secrecy is incomplete until the worker cannot read judge-only criteria.
rule 12
Adapter enforcement is prevent or detect — exactly as recorded.
rule 13
Cockpit, Ask, tracker, and cvg next never write canonical truth.
rule 14
Converge never merges the user branch, chooses portfolio work, or silently widens authority.
rule 15
Failure tokens and exit semantics are preserved — an error or exhausted budget is never success.
rule 16
End with the honest promise: Converge proves conformity to the encoded contract, not the wisdom of the original decision.
