OPERATIONS One safe next action CONVERGE · 0.2.0

Recovery follows tokens, not optimism.

“Compose status emits one NEXT=. Loop landings preserve the handoff and work that a human needs.”

one arrow per state · the recovery vocabulary
STATEWHAT THE SIGNAL MEANSONE SAFE NEXT ACTION
stale review
COMPOSE		 the recorded review digest no longer matches the current topology prepare / review again to refresh consent
interrupted materialize
COMPOSE		 finalization stopped mid-write; no half-completed receipt stands rerun idempotently — an exact rerun is byte-identical
EXHAUSTED EXIT 1
LOOP · SIGNED BUDGET REACHED		 budget spent before landing; handoff + worktree preserved raise the signed budget — or split the task
REFUTED
TIER 2 · ACCEPTANCE		 independent acceptance rejected the work fix the work, then resubmit to the same gate
CANCELLED EXIT 1
LOOP · EXTERNAL STOP SIGNAL		 the operator stopped the loop; written checkpoint/handoff preserved resume from the handoff
gap · current --resume
Under worktree isolation, --resume starts a fresh tree at attempt 1. Never imply continuation of uncommitted work — recovery resumes from the handoff, not from the old tree.
