BETWEEN, RESOLUTION, ORDER

Contention is explicit ordering, not optimistic parallelism

Two tasks sharing a resource require an explicit ordered contention or a dependency path. contention.between and contention.order must name the same two known tasks.

Between
Name the pair
Sibling tasks converge on one path — contention.between names the two known tasks in the collision.
Order
Fix the sequence
The order rail resolves the collision — contention.order names the same two tasks, in the sequence they may write.
No declared order
Fail closed
An unordered write overlap stops compile: TASK_GRAPH=COLLISION — order it, declare contention, or redesign the boundaries.
