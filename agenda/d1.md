## Stage — chapters for the PPT

Use this order. One idea per slide. The room does not know the domain yet, so the
business comes first and the punchline comes last.

### 1. Money arrives as files, once a night

- NorthWind Pay settles card payments for merchants. Money does not arrive as an API call.
- A batch lands overnight on SFTP. Java 21 parses it, Postgres holds it, the merchant is paid.
- Five live file types (`01`–`05`). Type `01` — card settlement — is the one we live in.
- Distilled from a real scar (Kurv), not a toy shop.

### 2. One file, opened

- Not JSON. Not CSV. **Fixed-width mainframe records** at byte offsets fixed by the contract.
- `spec/type-01-card-settlement/samples/valid-minimal.dat` — one `H`, two `D`, one `T`.
- Amounts are **signed overpunch**: the last character is the final digit *and* the sign.
  Positive `{ABCDEFGHI`, negative `}JKLMNOPQR`, scale 2. So `1234E` = `123.45`, `0500{` = `50.00`.
- The trailer declares `1734E` = `173.45`. Rows agree with the trailer. Batch accepted.
- The contract checks more than fields — `cross_record_rules` compare records against each other.

### 3. The same file, one letter different

- `df-source-001.dat`: every detail row is byte-for-byte identical.
- Only the trailer's last character changes — `E` becomes `D`. `173.45` becomes `173.44`.
- Measured with `cmp`: 338 bytes, **3 differ**, two of them are just the batch number,
  **one** carries the money (position 321).
- The file breaks its own rule: *trailer `net_amount_brl` must equal the exact sum of detail `amount_brl`*.
- **Keep the lie. Refuse the batch.** The refusal is a result, not a crash.

### 4. Green is not the goal

- Parse: PASS. Type-check: PASS. `D` is a legal overpunch character. Money: **−0.01**.
- Both honest greens are telling the truth. Field-level checks cannot see this.
- Only the **cross-record** rule catches it.
- **No oracle, no build.** A pack that cannot be adjudicated is refused before any modern file exists.

### 5. Inbound is not the contract

- [`spec/`](../spec/README.md) is how the customer arrived: estate + per-type inbound / samples / expected.
- [`contracts/`](../contracts/README.md) is the source of correctness. Inbound prose does not outrank it.
- Meetings, mail, and two dates of a proc will contradict each other. That is the work.

### 6. Two plants, same bytes (draw this)

There is already a working **legacy** line. We do not replace it. We build a **second** plant
beside it that reads the **same raw bytes**. If the two disagree, we **classify** — we do not
repair the source, and we do not edit frozen `legacy/` to go green.

Legacy (the base — already on the machine):

```text
SFTP raw/incoming → Java 21 → SFTP csv/outgoing
  → COPY staging.* → procedures → reporting.* → oracle
```

Modern (Days 2–4 — not on the tree yet):

```text

  → modern/landing/ Parquet    ← first write, NOT back to SFTP
  → dlt (register only) → DuckLake / DuckDB
  → dbt Bronze → Silver → Gold → golden-match → Dagster / FastAPI
```

## Craft — setup that survives any agent

People will show up with Claude Code, Codex, Kimi, Cursor, Oh My Pi, OpenCode, or nothing
but a terminal. **The curriculum is the repo and the gates.** The agent is a seat.

### Machine (required)

- Git
- Docker with Compose
- GNU Make
- Python 3.12 or newer

If these four work, every later day works. If they do not, stop. Do not debug an agent.

### Repo (required)

```bash
git clone <this-repo>
git checkout main          # or the signed tag base/2026-08-18 when it is on origin
make init
make deploy
make status                # postgres + four SFTP roles healthy
make run TYPE=01 SCENARIO=valid-minimal
```

Done when evidence shows `B202607230000001` **succeeded** and reconciliation **MATCHED**, net `173.45`.

Repeat of the same canonical batch needs a clean runtime:

```bash
make clean CONFIRM=clean-runtime && make deploy
```
