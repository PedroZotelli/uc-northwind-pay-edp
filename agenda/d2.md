### 3. The first write is not SFTP

```text
same SFTP raw/incoming
  → Python (model → parser → schema → writer → handler)
  → modern/landing/ Parquet + readiness manifest
```

Java writes CSV to `csv/outgoing`. Python writes Parquet to landing. Mixing those two destinations is a failed day.

### 4. The five-file package (draw this)

```text
modern/ingestion/src/northwind_pay/types/<number-name>/
├── model.py      typed records, exact Decimal
├── parser.py     transport, positions, grammar, encoding, signs
├── schema.py     validation, privacy-safe fields, controls
├── writer.py     deterministic atomic Parquet + metadata
└── handler.py    composes the four for one batch
```

Shared libraries may own checksums, idempotency, quarantine, provenance. Type grammar, privacy, rounding, and reconciliation stay inside the numbered package.

Bind must refuse writes to `legacy/`, `contracts/`, `gen/`, `infra/`. A polite system prompt is not a fence.
