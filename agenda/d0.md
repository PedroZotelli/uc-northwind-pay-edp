## Craft — setup that survives any agent

People will show up with Claude Code, Codex, Kimi, Cursor, Oh My Pi, OpenCode, or nothing but a terminal. **The curriculum is the repo and the gates.** The agent is a seat.

### Machine (required)

- Git
- Docker with Compose
- GNU Make
- Python 3.12 or newer

If these four work, every later day works. If they do not, stop. Do not debug an agent.

### Repo (required)

```bash
git clone <this-repo>
git checkout main          # or the signed tag base/2026-08-18 when it is on origin
make init
make deploy
make status                # postgres + four SFTP roles healthy
make run TYPE=01 SCENARIO=valid-minimal
```

Done when evidence shows `B202607230000001` **succeeded** and reconciliation **MATCHED**, net `173.45`.

Repeat of the same canonical batch needs a clean runtime:

```bash
make clean CONFIRM=clean-runtime && make deploy
```

### Agent (optional, bring your own)

Day 0 does **not** install one blessed IDE.

| Rule | Why |
|---|---|
| Any agent that can edit files and run shell can sit here | We grade gates, not vendors |
| The agent reads `README.md` first | Same operator surface for everyone |
| The agent must not write `legacy/`, `contracts/`, `gen/`, `infra/` | Frozen plant |
| Bind (from Day 2) is the fence | Paths and privileges, not “please don’t” |

**Demo (2 minutes, one volunteer per table):** open *their* agent, ask:

> Read `README.md`. Run `make status`. Do not change any file.

If `status` is healthy, the seat works. If the agent starts rewriting Java, that is the after-action.

### What to show of Converge on Day 0
